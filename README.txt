ENPÒTAN
- Pwodwi, pri ak rabè yo se EGZANP sèlman. Yo pa òf reyèl.
- Lyen vandè/afilye yo pa konekte ankò.
- Pa pibliye jiskaske ou verifye pri, pwodwi, kondisyon afilye, avi komisyon ak enfòmasyon kontak.
- Demo sa a pa gen kont itilizatè, baz done, peman oswa panèl administratè.

FASON KI PI FASIL POU TESTE GRATIS
1. Louvri index.html sou yon òdinatè pou teste konsepsyon an.
2. Pou teste sou iPhone/Android tankou app, mete dosye yo sou yon sèvis hosting estatik gratis ki bay HTTPS (pa egzanp GitHub Pages). Apre sa louvri adrès la nan Safari/Chrome.
3. iPhone: Safari > Share > Add to Home Screen (si opsyon an disponib).
4. Android: Chrome > meni ⋮ > Install app oswa Add to Home screen.

POU MODIFYE PWODWI YO
Louvri index.html epi chèche const products=[ ... ].
Chanje non, kategori, deskripsyon ak pri yo. Mete lyen reyèl sèlman apre verifikasyon.

PWOCHEN ETAP
- Chwazi pwodwi reyèl ak lyen legal/verifye.
- Kreye yon imèl kontak.
- Ajoute avi afilye.
- Teste sou plizyè ekran.
- Verifye kondisyon Amazon Associates oswa lòt pwogram anvan ou sèvi ak lyen yo.
